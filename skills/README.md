# Skills

Personal-use Claude skills built from the Origin Notes go-to-market teardowns (paraphrased, not verbatim).

- `gtm-tactic-library/` holds the knowledge base (`data/tactics.json`, 45 tactic cards, 59 conditions) and the tools (`scripts/search_tactics.py`, `scripts/tactic_fit.py`).
- The other folders are the 7 new skills and the 3 updated ones from the same batch.

Install a skill by zipping its folder and uploading it in claude.ai Settings, Capabilities, Skills, or by copying it into `.claude/skills/`.
